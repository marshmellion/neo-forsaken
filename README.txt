NEO FORSAKEN (test build, 2026-11-10)
The Forsaken Realms v1.28 (TheSAguy) played with NeoForge 1.0.50's table and deck builder (AdrianLopez98),
on the Forge rules engine (Card-Forge). Source: https://github.com/marshmellion/neo-forsaken

HOW TO PLAY (Windows 64-bit)
1. Unzip the whole folder somewhere with a short path, for example C:\NeoForsaken.
2. Double-click NeoForsaken.bat. The first launch takes about a minute while it reads the cards.
3. In the menu, open Adventure. The Forsaken Realms is the default plane. Duels and your decks open in
   NeoForge's table and deck builder; the world map, towns and shops are The Forsaken Realms' own.

Nothing is installed. Java is included in the jre folder. Your saves, decks, settings and downloaded card
images go in the "datos" folder created next to NeoForsaken.bat. To update, copy "datos" into the new folder.

IF IT DOES NOT START
Run NeoForsaken-debug.bat instead: it keeps a window open with the error. The logs are datos\neo\neo.log
and datos\neo\adventure.log.

THIS BUILD HAS NOT BEEN RUN ON WINDOWS. It was built and tested on Linux (menu, Adventure start, a duel,
the deck builder, the Ante Re-roll offer). Treat it as a first test build.
